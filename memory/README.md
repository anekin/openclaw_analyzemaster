## 恢复方法

复活时，将这些文件复制到新的 workspace 的 memory/ 目录：

```bash
# 从 GitHub 克隆后
mkdir -p ~/.openclaw/workspace-analyzer_agent/memory
cp memory/*.md ~/.openclaw/workspace-analyzer_agent/memory/
```

## 注意事项
1. 每日记录是原始日志，包含详细的工作过程
2. 重要内容应定期整理到 MEMORY.md（长期记忆）
3. 旧的每日文件可以归档，但建议保留至少30天

## 与 MEMORY.md 的关系
- **memory/YYYY-MM-DD.md**: 每日原始记录（详细、临时）
- **MEMORY.md**: 长期记忆（精简、持久）

定期回顾每日记录，将重要内容提炼到 MEMORY.md。
